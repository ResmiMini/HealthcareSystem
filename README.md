🏥 Healthcare Management System (MERN Stack)

A full-stack Healthcare Management System built using the MERN stack (MongoDB, Express.js, React.js, Node.js).
This system manages patients, doctors, staff, appointments, prescriptions, medicines, billing, and authentication with role-based access.

🚀 Features
🔐 Authentication & Authorization

Role-based login: Admin, Doctor, Patient, Staff

Secure authentication using JWT

Forgot / Reset Password functionality

👨‍⚕️ Admin Module

Approve / reject doctors

Manage doctors, patients, and staff

View dashboards and analytics

🩺 Doctor Module

View appointments

Access patient details

Add medical records

Create prescriptions with multiple medicines

🧑‍🤝‍🧑 Patient Module

Book appointments

View appointment history

View prescriptions and medicines

Make payments (Fake payment flow)

💊 Medicine & Prescription

Auto-generated Medicine IDs

Medicine category, dosage, duration

Multiple medicines per prescription

📅 Appointment Management

Calendar-based appointment booking

Displays only next 30 days

Appointment status tracking

💳 Payment (Mock)

Fake payment interface

Payment success simulation

Payment records saved to database
